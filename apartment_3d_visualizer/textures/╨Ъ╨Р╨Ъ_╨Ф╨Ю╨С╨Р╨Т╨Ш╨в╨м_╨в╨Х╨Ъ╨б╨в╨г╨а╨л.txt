КАК ДОБАВЛЯТЬ СВОИ ТЕКСТУРЫ
============================

Структура папок:
  textures/
    parquet/     ← текстуры для кнопки «Паркет»
    tile/        ← текстуры для кнопки «Плитка»
    concrete/    ← текстуры для кнопки «Бетон»
    carpet/      ← текстуры для кнопки «Ковёр»
    marble/      ← текстуры для кнопки «Мрамор»

В каждую папку кладите файлы текстур. Аддон ищет их по ключевым словам в имени:

  Диффузный цвет   → файл содержит: diff / color / albedo / basecolor / col
  Шероховатость    → файл содержит: rough
  Нормаль          → файл содержит: nor / normal / nrm

Поддерживаемые форматы: .jpg  .png  .exr  .tga  .hdr

Пример (паркет ёлочкой от ambientCG):
  herringbone_parquet_diff_1k.jpg     ← диффузный цвет
  herringbone_parquet_rough_1k.exr    ← шероховатость
  herringbone_parquet_nor_gl_1k.exr   ← нормаль

Можно класть несколько наборов в одну папку — аддон возьмёт первый подходящий файл.
Если файлов нет — используется процедурная текстура (не нужны никакие файлы).

ГДЕ ЛЕЖИТ АДДОН:
  Blender → Edit → Preferences → Add-ons → Apartment 3D Visualizer
  Нажмите на треугольник рядом с аддоном → увидите путь к файлу.
  Папка textures/ находится рядом с __init__.py
