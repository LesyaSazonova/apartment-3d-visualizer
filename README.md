# apartment-3d-visualizer
Apartment 3D Visualizer — аддон для Blender, который преобразует растровый 2D-план квартиры в простую 3D-модель. Аддон распознаёт стены, оконные и дверные проёмы, строит геометрию помещения, создаёт пол, позволяет настраивать высоту и толщину стен, материалы и базовое оформление сцены.
